How collection works

  1. Runs automatically (default every hour, first run ~20 s after startup) and on demand.
  2. Fetches each enabled feed over HTTP(S) with a timeout and size limit; local/private addresses are refused.
  3. Parses RSS/Atom, strips HTML, keeps the original link and publication date.
  4. Skips duplicates: same normalised URL (tracking parameters removed), or the same headline within 7 days.
  5. Classifies category, region, companies and an importance score from the text (rule-based).
  6. Records success or the exact error per feed. Collected items older than the retention period are purged.

Permanent sources can be added in application.yml under radar.news.feeds. No feed currently needs an API key; if one does, put it in an environment variable — it is never sent to the browser.
